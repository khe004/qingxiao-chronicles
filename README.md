# qingxiao-chronicles

青霄纪

## 青霄论道

根据《修仙游戏属性与战斗系统设计方案.md》实现的网页版单人斗法原型。

## 运行

无需安装依赖，在本目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000`。页面使用 ES modules，应通过 HTTP 服务打开。

## 已实现

- 火木法修、太玄剑修各 8 个神通，开战前从本派装备 6 个；通用行动和应对不占槽位。
- 每派有两个主修方向，效果与基础心法同时生效：引燃爆发 / 生息消耗、快剑压制 / 藏锋重剑。
- 配装界面支持查看主修规则、神通费用与距离、一键推荐、槽位校验。打开时暂停战斗，取消沿用原局，应用后开启新局；重新论道保留当前配置。
- 每回合 3 行动点、5 点纳气、10 点灵气容量，灵气跨回合保留。
- 近、中、远三档距离，以及固定预告的敌方招式计划；神通卡标明有效距离与当前是否超距。距离只限制技能有效范围，不直接改变伤害。追风剑只适合近身，普通剑招和其他打断技适合近中距，蓄势大招适合中远距且释放时检查距离，常规火法和自身恢复、防守不限距离。
- 血条、状态、人物和场内文字各有独立空间，状态增加时自动撑开布局，兼容手机与桌面。
- 灵种、灼烧、剑意、破绽、护盾、蓄势与打断。蓄势后仍可使用剩余行动移动、调息或施展已装备的防守招式，其他神通锁定；下次行动开始免费释放，费用与伤害不变。
- 每回合一次手动应对窗口，敌人也有按资源限制的应对。
- 通用基础攻击、移动、调息与净息。
- 战斗记录、技能费用与伤害预估、指南、胜负结算、重新开始。
- 本场斗法纪要完整保留，无条数上限；向上翻阅旧记录时不自动跳到最新，重新论道或切换流派时清空。
- 自动斗法支持均衡、强攻、稳守、蓄势四种倾向及三档出招节奏，可随时暂停转手动；出招、应对与选择理由均写入纪要。
- 桌面与移动端布局，以及支持浏览器中的 WebMCP 状态读取和行动接口。

## 原型取舍

- 固定玩家先手，不实现先手属性争夺。
- 同境切磋，气血耗尽即认输，不实现寿元与永久伤势。
- 不实现法宝装备与词条编辑、成长养成、存档、多人联机与更多流派。
- 灵气超过容量时按功法生成顺序接收至容量上限，剩余溢出；暂未实现自选保留顺序。
- 灼烧在目标行动阶段开始时结算，持续 3 次，穿过护盾；护盾跨回合保留，上限 60。
- 任意灵气费用优先消耗通灵，再消耗当前数量最多的属性。

## 文件

- `dist/index.html`：页面结构。
- `dist/style.css`：界面与响应式布局。
- `dist/engine.mjs`：独立战斗规则与敌方计划。
- `dist/loadout.mjs`：主修与神通配装界面、草稿配置和推荐搭配。
- `dist/auto.mjs`：自动战斗规划与应对策略，四种倾向使用不同的攻防与铺垫权重。
- `dist/app.mjs`：页面交互、动画与战斗流程。
- `dist/assets/`：斗法场景与角色美术。

数值用于试玩验证。已建立确定性 AI 对局的平衡基线，并完成第一轮蓄势行动窗口修订；技能数值与主修奖励未变，尚待真人验证。参见 [历史基线](docs/平衡性基线报告.md) 与 [本轮配对对照](docs/蓄势行动窗口修订对照.md)。

## 验证

```sh
node test-engine.mjs
node test-auto.mjs
node test-loadout.mjs
node test-charge-window.mjs
```

已通过资源、连招、距离、蓄势、打断、应对及 80 场完整对局检查；两种流派与四种倾向的 8 场自动对局也全部通过。新增配装验证覆盖四个主修、四个新技能、资源不可变性、藏锋失效与蓄势消费，以及 32 场配置自动对局和一场超过 160 条纪要的长局。已完成桌面与移动端配装、取消保留原局、应用重开、配置保留、自动暂停恢复、手动应对、完整纪要和 WebMCP 共用状态的浏览器检查。

自动斗法会比较本回合可行的出招组合，并依据已公开的敌方计划估计后续攻防收益。全部动作使用相同战斗规则，不能绕过行动点、距离、灵气或应对次数。开启自动时暂时禁用手动技能；暂停后可以继续当前对局。重新论道与切换流派会停止自动动作。

设计文档见 `docs/修仙游戏属性与战斗系统设计方案.md`。

后续扩展顺序与当前完成项见 [ROADMAP.md](ROADMAP.md)：先做深两派内部打法，再扩展对手和短挑战，随后增加土系体修，最后推进金丹突破。

## 平衡性测试

```sh
node test-balance-harness.mjs
node scripts/balance.mjs --out docs/balance/charge-window
node scripts/balance-compare.mjs
```

完整枚举约需 6 分钟。涵盖 1824 个对等 AI 对局、384 个蓄势战术场景、64 个只关闭生息额外回血的配对，以及 16 个原网页脚本对照。场景是确定性的，不是独立随机样本或真人胜率；双方使用同样的行动和应对控制器，先手、起始距离和配装单独记录。线上仍固定玩家先手；敌方公开脚本现可执行预告的蓄势后防守、移动或调息。报告附逐场 CSV、聚合数据和压缩原始记录，可重复比较后续版本。旧基线保存在 `docs/balance/`，本轮输出在 `docs/balance/charge-window/`。上面的命令复现本轮；生息单因素的 64 组结果属于历史基线，其生成器应在对应历史源提交运行，避免用当前规则覆盖旧数据。
