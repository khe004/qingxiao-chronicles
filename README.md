## 青霄论道

根据《修仙游戏属性与战斗系统设计方案.md》实现的网页版单人斗法原型。

## 运行

无需安装依赖，在本目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000`。页面使用 ES modules，应通过 HTTP 服务打开。

## 原型取舍

- 固定玩家先手，不实现先手属性争夺。
- 同境切磋，气血耗尽即认输，不实现寿元与永久伤势。
- 当前实现六派十二主修；法宝装备与词条编辑、成长养成、永久存档、多人联机和新流派留待后续。
- 灵气超过容量时按功法生成顺序接收至容量上限，剩余溢出；暂未实现自选保留顺序。
- 灼烧在目标行动阶段开始时结算，持续 3 次，穿过护盾；护盾跨回合保留，上限 60。
- 任意灵气费用优先消耗通灵，再消耗当前数量最多的属性。

## 平衡性测试

```sh
node test-balance-harness.mjs
node scripts/balance-heal.mjs
node scripts/balance-heal.mjs --expand heal18
node scripts/balance-heal-report.mjs
```

本轮约需 7 分钟。先独立筛选回春 26 / 22 / 18 恢复，以及恢复 26 但只清 2 层灼烧，核对 144 个基准场景；随后为采用的 18 点档补齐配装。实际执行 2232 场完整对局与 96 个有限灼烧片段。采用值矩阵包含 1824 个场景，其中复用已测采用值 432 个、未装备回春且规则不可触发的基准场景 216 个；这些不算新增独立对局。每档引擎相互隔离，自动模拟采用对应数值，控制器内容保持不变。

回春采用基础恢复 18，全清灼烧不变。生息推荐配置的全距离胜出占比从 79.7% 降至 75.0%，中距从 79.7% 降至 71.9%，远距仍为 84.4%。引燃全距离从 59.9% 降至 53.1%。对剑修自选配装的生息占比仍为 91.7%，后续优先复查射程、移动行动与 AI 预测，避免继续叠加恢复削弱。结果为确定性场景占比，不是真人胜率。

当前剑修没有施加灼烧的技能，单独削弱回春清灼烧不会直接改变火木对剑修对局；清除候选的交叉结果按结构性结论复用，另外实际测试了火木镜像与灼烧片段。

旧数据保留在 `docs/balance/`、`docs/balance/charge-window/`、`docs/balance/sustain-recovery/`；本轮在 `docs/balance/heal-recovery/`。上面的命令复现本轮；旧生成器应在对应历史源提交运行，避免以当前规则覆盖旧数据。通用矩阵可用 `node scripts/balance.mjs --out docs/balance/自选新目录` 输出到新目录。线上仍固定玩家先手，敌方执行公开预告。

## 射程与接近成本修订

本轮仅将焚炎术从全距离改为近身 / 中距；伤害、费用、回血与线上自动控制器保持不变。催生术、流火诀、星火引仍支持远距，离火焚天仍限中远距；剑修接近不返还行动。技能卡、配装与指南同步标明有效范围。
