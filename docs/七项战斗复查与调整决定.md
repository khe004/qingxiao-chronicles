## 方法与边界

- 当前规则：生息额外回血 2、回春基础回血 18、焚炎近中距、蓄势允许剩余行动移动／调息／防守。
- 独立离线副本使用「敌方护盾净变化评分 × 2」；**线上自动战斗仍使用已发布控制器**。这不是一次偷偷修改线上 AI 的实验。
- 所有对照交换先手；同一候选对照维持技能、倾向、距离、对手配置与控制器一致。不同控制器的结果单独展示。
- 30 回合未决表示达到观察上限，不算平局或无限循环。第 1、2 项行为观察上限为 12 回合。
- 数据为确定性策略运行，无随机抽样置信区间；多种配置覆盖也不等于真人胜率。
- 原始事件、全部纪要、源代码快照及 SHA 保存在 `docs/balance/sequence-N/`，可用对应脚本复跑。计数区分新执行、缓存与决策点重放。

## 1. 两阶段复评

已完成。原有十二候选先按原边界预测评分，然后取「停止＋前三个高分组合」统一深评。最终竞争者全部用深评后的评分，避免混用两种时间线的得分。深评对手使用冻结的旧 adaptive 策略；有限递归，不假定对手也采用新复评策略。

四个固定决策点各跑两个模型，共 8 次根决策；另外对入选组合重放旧对手，质量指标仅针对这个已知策略。基础模型相对十二候选中的已知策略最优得分差为 `0 / 12.78 / 0 / 14.68`，复评为 `0 / 0 / 0 / 11.76`。改善了部分决策，但筛选仍漏掉一个最佳组合。四点平均选招约 74ms → 848ms；不是全量加深，也仍超过直接替换所期望的成本。

8 场独立行为对照：快剑镜像中距、双方先手交换，生息对重剑中距、双方先手交换，各两模型。快剑四场均在 12 回合未决；原模型甲／乙剩余气血为 120／68（交换先手镜像），复评为 209／187，不能宣称解决了拖延。生息先手原模型获胜，改复评后重剑获胜；生息后手两模型均败。这说明改变预测会改变看似的流派强弱。

**决定：保留复评为诊断工具，不替换默认平衡控制器或线上 AI。** 本轮继续用原有限层策略作为稳定对照；全量深层与复评都不能单凭少数已知策略重放结果成为数值裁判。

数据：[第 1 项摘要](balance/sequence-1/summary.json)。复跑：`node scripts/sequence-search.mjs 1`。

## 4. 平衡测试控制器组合

**采用控制器组合，不采用单一裁判：**

- `adaptive`：原有限层、十二候选、敌盾净变化评分 ×2，作为主要行为复查；可能有边界误判和候选遗漏，不能认定最优策略。
- `immediate`：看本阶段收益，作为低预测成本的筛选与消融控制；天然低估未来蓄势与持续收益。
- `script`：双方共享对等规则、用固定公开脚本预测对手，作为脚本敏感性控制；实际双方会重新决策，预测也会失配。
- 线上 `legacy`：仍服务真实网页的公开预告玩法，其对等离线胜率保留在历史四控制器报告；本轮未重跑。真人复查尚未进行。

数值候选先用 immediate／script 单因素配对，再用 adaptive 确认重点。控制器间矛盾时保留原值、记录分歧，不能选择最符合预期的一个结果。第 1、2 项新模型只作为诊断，不进入本轮数值裁判。

数据：[第 4 项摘要](balance/sequence-4/summary.json)。复跑：`node scripts/sequence-review.mjs 4`。
