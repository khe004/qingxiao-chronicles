# 蓄势招式动画

v0.13.2 为已实装的四道蓄势招式提供不同动作。木、水目前没有蓄势招式，不为动画新增规则或技能。

| 招式 | 蓄势 | 释放与命中 |
| --- | --- | --- |
| 万剑归一 | 环身剑阵，青金色剑光 | 剑光合流飞出，命中斩光与碎芒 |
| 离火焚天 | 地面火纹，橙红流焰与上升余烬 | 三股流焰卷向对手，火柱升起，余烬散开 |
| 赤日临空 | 头顶凝聚赤日，日冕与引气丝线 | 赤日掠空坠落，落光与圆形余辉消退 |
| 镇岳印 | 地阵、浮岩和山纹印 | 山印自上而下压向目标，地面震纹与碎石散开 |

动画只读真实战斗事件。右方释放且等待玩家应对时，蓄势提示保留；应对结算后播放释放与命中。全部护盾抵御时额外显示蓝色护盾轮廓。取消、打断或距离落空只消散，不播放命中；重复渲染不重复播放。重新论道、换装或切换对局会清理剑阵、法阵、飞行物和清理计时器。

特效限于人物演武区，不遮住气血、状态或操作区。支持双方男女立绘、近中远位置变化和手机布局；系统开启减少动态效果时保留静态蓄势图案、招式名与简短命中提示，移除飞行、旋转、坠落及碎片运动。

## 试看

- 万剑归一：太玄剑修任一推荐搭配，直接蓄势。
- 离火焚天：火木法修「引燃爆发」推荐搭配，先调息或施展木法凑足火气，再蓄势。
- 赤日临空：离火法修「焚灼消耗」推荐搭配，直接蓄势。
- 镇岳印：厚土法修「镇岳压制」推荐搭配，先筑垒，再蓄势。

点击「完成蓄势」，下次自身行动开始且未被反制时释放。木法若消耗行动后缺气，可跨回合储气再尝试。

## 验证

运行 `node qa-charged.cjs`，覆盖三道新增动画的真实页面行动、完整蓄势到释放、取消、双方施法、男女立绘、1440 / 390 / 320 像素、手动应对前后、超距、打断、护盾全抵御、重复渲染、重开清理、减少动态效果与原生浏览器动画时间轴。运行 `node qa-unity.cjs` 回归首道剑阵。
