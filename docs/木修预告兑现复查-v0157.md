# 木修预告兑现复查 · v0.15.7

本轮扩大共生、寄生面对不同玩家配装与打法的复查，并补上部分准备的接近收获路线。繁花击／噬藤收获有1～2层准备时，远距不能用，近中距仍能用；公开备用策略现在可以花1行动接近，保留原主招，再按原费用收获。应对预算同时识别这条路线，避免忽略最后木气的用途。

准备归零、只剩1行动或灵气不足时不强行接近；满3层已经能远距收获，不多花移动行动。主招预告、技能费用、准备消费、真实反应与原六槽沿用。该共享备用策略同时适用于实际论道、自选1对1和公开预测。

## 扩展样例及结果

两位木修各面对十二套流派均衡样例，六类代表样例再测强攻／稳守，每套近中远三距离。每版144问道、36均衡切磋，固定玩家先手、30回合上限，共新执行360场。

| 难度 | 原玩家胜／NPC胜／未决 | 采用版玩家胜／NPC胜／未决 |
| --- | --- | --- |
| 问道 | 136／8／0 | 136／8／0 |
| 切磋 | 34／0／2 | 34／0／2 |

两位木修原版各有4/72问道胜局，集中在镇岳中／远距，扩展前的每位两套玩家样例没有覆盖这些结果。不能把新增覆盖的胜局算成本轮修正增强。切磋两场未决也是共生对镇岳中／远距，30回合内未结束，不推断为无限循环。

360场中仅2场问道轨迹／气血变化，胜负不变；36个切磋场景完整结果、统计和日志一致。自然对局中没有触发本次部分准备接近修复。12个同输入手动棋面中，4个部分准备棋面以前跳过收获后补气／换招，采用版接近后按原主招收获；另8个边界行动与棋面相同。采用依据是公开备用策略的确定遗漏，不能据此声称自然问道难度提升。

## 预告失效的分类

[逐原因计数与十二流派／打法小表](balance/wood-previews-v0157/report.md)区分玩家破除生长、玩家净化寄生、自身先前收尽准备、准备已经满层、净化对象已消失、费用、行动与射程。

旧远距检查会先返回“需满3层”，即使实际准备已是零。本次记录按尝试时实际层数归因：两次自然远距收获失败均已被玩家破除为零准备，仍应换招；不会凭空把零准备视作可接近收获。失败动作本身不扣行动，成功备用招正常付费，两档NPC均没有未用行动。

费用原因也保留边界：“补回应对支出可支付”只表示补回实际应对开支后该招费用足够；致命保命仍有优先级。共享生长已用于回春或蔓屏时，后续预告繁花击失效与玩家破除不同，不能重复收获同一份准备。

共生的切磋样例累计回复较多，原有提前回春与后续繁花共用资源仍值得继续复查；寄生原六招没有回春，不因统计中出现公共净息回复就解释成新增恢复能力。这轮没有改职业数值、六槽或性格权重。

## 验证和数据边界

新回归覆盖32个准备／行动组合，另测缺气、应对预算、冻结主招与真实阶段／公开预测一致性。1590动作／释放、595完整阶段、现有木土自然行为、备用策略、蓄势预算、存档等相关回归通过；真实网页均衡／强攻／稳守及1440／390／320布局验证通过。

共享备用策略可能影响木修对阵，因此另新执行原均衡独立双AI中涉及木修的276条，胜方、回合、气血、统计和完整轨迹均相同。原表其余660条与稳守历史矩阵未补跑、不计入新执行分母。此次636次新增完整执行分为360实际NPC游戏和276独立兼容重放；夹具、回归、历史观察器核对与浏览器片段不加入完整游戏分母。
