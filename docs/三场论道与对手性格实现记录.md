# 三场论道与对手性格实现记录

## 已实现的体验

首页「三场论道」可选两条路线：

- 试剑问火：顾追风（快剑）→林知春（生息）→裴藏锋（重剑）。
- 观火问剑：温照夜（引燃）→顾追风（快剑）→林知春（生息）。

每场开始时恢复气血、灵气与状态；第2场从远距开局，其余中距。固定玩家先手。每场最多30回合，超时记未决；胜、败、未决均可进入下一场。场间可更换流派、主修和六个神通；战斗中配装锁定，重开本场后使用原配置。关闭备战配装会沿用当前配置入场。

四名对手也可单场挑战。允许与玩家同派，沿用现有立绘。

## 对手的区别

| 对手 | 六槽配置 | 行为方向 |
| --- | --- | --- |
| 顾追风 | 掠影、照隙、断岳、藏锋、截脉、追风 | 主动进入剑招射程，养意后追击或重剑，遇蓄势优先打断 |
| 裴藏锋 | 掠影、照隙、断岳、藏锋、回澜、归一 | 计划中保留应对金灵气，护体养意、识破、利用藏锋，已有进攻机会就出剑 |
| 温照夜 | 催生、流火、焚炎、星火引、缠灵藤、离火 | 铺种后引燃，远距分燃，多层灵种时接近引爆，已有灼烧才择机蓄势 |
| 林知春 | 催生、流火、焚炎、回春、枯荣、缠灵藤 | 灼烧施压；按伤势、灼烧和木气选择恢复，每阶段至多主动恢复一次，保留进攻机会 |

对手的行动计划在玩家阶段开始时生成并固定。玩家改变距离、消耗敌方应对灵气或打断蓄势，可以让预告招式失效；敌方只跳过，不临时补招。下一阶段才重新规划。预告及实际决策理由均可查看。

`ChallengeBattle`在原引擎之上实现人格与统计，未修改技能费用、伤害、主修奖励。原单场固定脚本玩法保留。玩家自动搜索的挑战副本保留挑战类型，因此预测使用同一人格、预告与时限；旧玩法仍走原预测路径。没有合并第1、2项研究中的深评、多样性或评分调整。

## 纪要与回顾

每场保留全部纪要与独立战后快照。完成的场次、旧轮次以及中止／重开的已记录场次，都可在「论道记录」选择回看，不被新局覆盖。

回顾对比双方的实际招式气血伤害、盾伤、恢复、溢出、剑意消费、移动与闲置行动，以及蓄势的开始、释放、打断、距离落空、取消、战斗结束仍未释放和实际伤害。灼烧在纪要中另行结算。统计只观察真实战斗，不把搜索副本算入。

「复制全部纪要」包含所有已记录场次；浏览器不允许剪贴板写入时，显示可全选复制的完整文本。

这是当前页面的一次游玩记录，刷新或离开会清空。界面明确提示并提供复制；本轮没有实现账号存档、跨设备或永久历史。

## 验证与限制

- `test-challenge.mjs`：24完整对局、三距离、两派对手配置、公开计划冻结、搜索不改变真实战斗、蓄势去向、斩杀／打断窗口和时限。
- `test-trial.mjs`：三场状态流转、胜败未决、资源重置、存档幂等／不变、重开与保留旧轮次。
- `qa-challenge.cjs`：真实浏览器走完三场自动战斗，场间换派／主修，关闭配装沿用入场，暂停／弹窗、新轮次、同派对局、完整复制回退，1440／390／320宽度与立绘不被血条遮挡。
- 原引擎、自动、配装、公开预测及对等擂台回归检查通过。第一至七项原始数据仍可按冻结源码审计。
