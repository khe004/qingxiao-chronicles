# 青霄纪 · 流派与分支规划

日期：2026-10-02

性质：设计规划，暂不实施；本轮暂停数值调整。

依据：《修仙游戏属性与战斗系统设计方案.md》与现有斗法原型。

本文只确定流派、分支与设计方向，不列具体技能、费用、伤害或属性数值。下表是候选内容蓝图，分阶段推进，不代表全部同时制作。

## 参考与分类原则

| 参考 | 采用的方向 | 在本项目中的体现 |
| --- | --- | --- |
| 《太吾绘卷》 | 距离适性、出招条件、攻防应对、同类武学的打法差异 | 流派争夺不同的距离与出手机会，分支改变攻守节奏 |
| 《觅长生》 | 五行灵气、功法构筑、状态联动、相生组合 | 主修决定资源循环，辅修连接机制，混合路线形成自己的收益兑现方式 |
| 原设计方案 | 每派都有启动、维持、兑现、防守与可利用的弱点 | 各派都有明确取舍，境界成长逐步解锁分支与规则变化 |

以下名称与机制是本项目的设计建议，不是两款参考作品的原作流派清单。

“流派”按主要战斗循环划分，“分支”按同一循环的使用方式划分。五行是可跨流派使用的属性，不要求每个流派固定绑定一种灵根；宗门也不等于流派。同一流派可以有不同师承，不同流派也可以共享部分属性。

## 流派总览

| 流派 | 战斗定位 | 核心循环与关键选择 | 规划阶段 |
| --- | --- | --- | --- |
| 剑修 | 单体攻杀、节奏压制、条件爆发 | 积累剑意、制造破绽，再决定持续压制还是集中兑现 | 已有基础，先深化快剑与重剑 |
| 火木法修 | 铺垫爆发、灼烧与续航 | 用木系培育铺垫，在立即引燃与保留长期收益之间选择 | 已有基础，先深化引燃与生息 |
| 体修 | 近身争夺、承伤反击、主动破势 | 建立近身或守势优势，选择继续承接还是转为进攻 | 优先新增，先做土系反震方向 |
| 水法修 | 距离控制、资源调节、化解攻势 | 扰乱对手节奏，为自己创造施法或资源周转窗口 | 后续优先，补充控制型对手 |
| 木法修 | 灵植成长、寄生侵蚀、持续收益 | 培育或寄生，选择保护长期投入还是提前收获 | 后续扩展，从火木体系中形成独立循环 |
| 土法修 | 阵地防御、稳固蓄势、镇压空间 | 建立壁垒与阵地，再选择守住阵地还是向外施压 | 后续扩展，与体修明确区分 |
| 神魂修 | 心神干扰、识破意图、魂印兑现 | 布置精神威胁，选择妨碍行动还是集中兑现魂印 | 进阶扩展，需要完善精神应对 |
| 阵修 | 战场布置、阵眼保护、规则组合 | 布置并连接阵纹，选择补齐阵势、保护阵眼或启动阵法 | 进阶扩展，需要可交互的战场物件 |
| 御器修 | 法宝运转、攻防调度、核心器物养成 | 调配器物职能，在持续轮转与集中驱动之间选择 | 进阶扩展，需要法宝与本命法宝系统 |

## 各派分支

| 流派 | 分支 | 设计方向 | 主要取舍与对手应对 |
| --- | --- | --- | --- |
| 剑修 | **快剑压制**（已有） | 频繁出手、试探应对、滚动积累剑意，抓住短暂破绽 | 需要持续取得主动；逐段防御、卸劲和反击可抑制连续进攻 |
| 剑修 | **藏锋重剑**（已有） | 防守养势，等待破绽，以蓄势兑现集中攻势 | 铺垫期间必须承受压力；对手可试探、打断或改变距离 |
| 剑修 | 御剑游斗 | 以飞剑与身法维持适合自己的距离，边调整位置边积累攻势 | 空间被压缩时循环受阻；必须在追击与保留机动能力之间选择 |
| 剑修 | 心剑反制 | 识破敌方意图，以剑意干扰锁定和施法，寻找精准反击窗口 | 依赖判断时机；多种进攻路线或不受心神影响的敌人能降低收益 |
| 火木法修 | **引燃爆发**（已有） | 木系铺垫转化为火系爆发，决定何时消耗已有铺垫 | 提前兑现会损失后续收益；对手可清除铺垫或针对爆发准备防守 |
| 火木法修 | **生息消耗**（已有） | 保留部分生长收益，以恢复、灵气周转与持续灼烧维持压力 | 防守与进攻争夺资源；急促进攻、铺垫清除和周转干扰可迫使其改变节奏 |
| 体修 | **土系反震**（优先新增） | 承接攻击、卸劲积势，再选择反震或主动破势 | 守势需要投入；对手可小攻击试探、暂缓进攻或改用持续侵蚀 |
| 体修 | 刚拳破势 | 主动近身、连续迫压，以肉身攻势破坏防守与蓄势 | 追击会占用进攻机会；拉开距离和限制移动可以打乱循环 |
| 体修 | 游身截击 | 借身法调整近身位置，在对手出招和移动时寻找截击窗口 | 需要判断与机动空间；稳定阵地和范围压制会限制发挥 |
| 水法修 | 寒凝控距 | 通过凝滞、牵引与距离调整延缓对手攻势，创造反击窗口 | 控制需要持续维护；稳固、脱困与快速贴近能打破节奏 |
| 水法修 | 潮汐调息 | 以资源调节和攻守转换维持循环，在顺畅运转时集中兑现 | 调节资源本身也占用行动；持续施压可压缩准备空间 |
| 木法修 | 灵植共生 | 培育灵植，将生长收益分配给恢复、防护或进攻 | 需要保护场上投入；对手可以破坏灵植或抢在成型前压制本体 |
| 木法修 | 毒藤寄生 | 在敌方身上建立持续侵蚀，限制行动并等待寄生增长 | 对净化和速战敏感；需在继续叠加与兑现已有寄生之间选择 |
| 土法修 | 壁垒守御 | 建立稳定阵地，保护自己与蓄势过程，再寻找安全反击窗口 | 阵地成型较慢，转移有代价；穿透、侵蚀与迫使迁移能削弱优势 |
| 土法修 | 镇岳压制 | 用镇压与空间约束限制敌方移动，为后续攻势创造条件 | 必须持续维持压制；机动脱离和快速打断可破坏布置 |
| 神魂修 | 魂印攻心 | 累积魂印并观察敌方心神状态，选择干扰或集中兑现 | 魂印可能被清除；镇心和心神防护可延后其收益 |
| 神魂修 | 幻惑扰识 | 干扰感知与锁定，让对手难以顺畅执行原有计划 | 幻惑要有可辨认线索；稳定范围攻势与破妄应对可减轻影响 |
| 阵修 | 封界镇阵 | 以阵眼连接形成限制区域，保护阵势并引导对手进入不利位置 | 建阵期间需要应对压力；对手可拆阵眼、脱离区域或直接压制本体 |
| 阵修 | 五行转阵 | 调整阵纹关系，改变灵气转化与攻防收益，按对手调整阵势 | 转阵需要付出准备代价；拆除关键连接可迫使其重建循环 |
| 御器修 | 多器轮转 | 在不同器物之间调度进攻、防守与辅助，保持轮转顺畅 | 操控与资源存在竞争；干扰轮转或逼出错误调度可制造空隙 |
| 御器修 | 本命专精 | 围绕核心法宝蓄养、驱动与回收，集中构筑其独特战斗规则 | 收益集中于核心器物；被干扰运转时需要有补救手段 |

## 容易重叠的方向如何区分

| 容易混淆的方向 | 区分原则 |
| --- | --- |
| 藏锋重剑 / 土系反震体修 | 重剑围绕剑意与破绽兑现；体修围绕承接、卸劲和破势。两者的防守收益来源不同 |
| 土系体修 / 土法修 | 体修以肉身和近身交锋为核心；土法修以灵气、阵地与空间限制为核心 |
| 生息火木 / 独立木法 | 火木需要决定木系铺垫是否转成火势；木法保留生长本身，将其用于共生或寄生 |
| 御剑游斗 / 御器修 | 御剑仍围绕剑意、剑招和破绽；御器围绕器物运转、职能调度和回收 |
| 心剑 / 神魂修 | 心剑的识破与干扰服务于剑道攻杀；神魂修的主要循环由魂印和精神状态构成 |
| 土法阵地 / 阵修 | 土法的阵地是攻防手段；阵修的阵眼、连接与阵势本身是主要战斗对象 |

## 混合与进阶路线

先让基础流派独立成立，再开放能够连接两种循环的辅修。火木已经成立，作为混合流派的样板；其他组合先作为构筑方向，不立即新增独立职业。

| 候选方向 | 设计方向 | 开放条件 |
| --- | --- | --- |
| 水木共生 | 水系调节帮助灵植成长，将控制窗口转化为长期收益 | 水法、木法各自有完整循环 |
| 土金破阵 | 土系镇压制造出手机会，金系或剑道集中兑现破绽 | 镇压与破绽的互动清晰可应对 |
| 血火 / 血体 | 以自身风险换取进攻窗口，需在恢复与继续付出代价间选择 | 自损、恢复与风险提示规则完善 |
| 雷法 | 偏向积蓄与快速兑现，突出施法节奏变化 | 基础术法框架成熟，先作为术法分支评估 |
| 风法 | 偏向距离调整、牵引和施法位置变化 | 距离与移动玩法成熟，先作为机动分支评估 |

冰法优先归入水法的寒凝方向；毒优先归入木法的寄生方向。暂不为雷、冰、风、毒各自建立独立资源池。

## 制作顺序建议

| 阶段 | 内容范围 | 目标 |
| --- | --- | --- |
| 近期 | 深化现有快剑、重剑、引燃、生息；新增土系反震体修 | 让压制、蓄势、铺垫、续航、承接反击形成不同对局体验 |
| 中期 | 优先水法，再评估独立木法与土法；逐步加入御剑游斗、主动近身体修等分支 | 扩大距离控制、持续投入与阵地战的差异 |
| 远期 | 神魂、阵修、御器及跨派混合；结合境界开放进阶分支 | 在已有框架上增加精神、战场物件与法宝运转的决策 |

每新增一个流派，先实现一个能独立运转、能被应对的分支，再扩展其他分支。境界提升主要用于解锁新的规则与构筑空间，不把全部分支绑定到同一次突破。

当前继续以一对一斗法为基础。灵植、阵眼和法宝先作为战场物件或状态表现，不直接扩展为多人回合系统；幻惑也不得让已明确承诺的敌方蓄势预告失去可信度。

判断分支是否成立，重点看它有没有改变距离偏好、资源使用、攻守时机或收益兑现方式。若只换了元素、名称或伤害表现，优先作为同一分支的内容变化，而不单列新分支。
