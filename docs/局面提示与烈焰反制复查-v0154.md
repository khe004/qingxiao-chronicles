# 局面提示与烈焰反制复查 · v0.15.4

在敌方预告下展开「局面提示」。它随每次出招更新，围绕当前双方配装、状态、距离、行动与灵气解释取舍：

- 当前能接的两招，以及准备已满足的消费出口。
- 支付移动后是否还够行动和费用出招；敌方蓄势如何一步超距或打断。
- 清灼烧、净寄生、破生长各占行动；破除与打断的区别。
- 反击的次数和期限，以及出招与护盾应对共用灵气。
- 玩家行动、敌方行动、应对与结束分别给出对应提示。

默认收起；展开不会暂停自动斗法。提示只解释当前可行性，不保证最优或必胜。两招检查在隔离副本中调用实际结算，包含真实敌方应对、位移、反击与寄生侵蚀；副本不复制历史纪要和累计统计，原局状态、队列、纪要与记录不变。原局出招后重新核对，所以先净化或移动可能失去之前的连招窗口。

例如烈焰样例开场「附焰术→焰海横流」占满3行动。先花1行动净寄生，则这条完整连招当回合放不下；已经附焰后，提示会转为当前可用的焰海兑现出口。它呈现同一份行动和储备的竞争，帮助玩家自行选择。

## 烈焰弱格的实测结论

[研究表](balance/fierce-window-v0154/report.md)包含48场单槽筛选与12场冻结源码的实际页面引擎对照。原双筹划样例对共生、寄生均0/6；四个替换对共生仍0/6，对寄生最好1/6，只在近身、烈焰先手胜出。没有采用替换，也没有以这一格补齐全对手或宣称整体改善。

页面实际对手执行公开预告；玩家侧使用均衡自动。烈焰在玩家侧对两种木修各3/3，交换职业后木修在玩家侧也各3/3。双方控制器与预告约束不同，不能与对等双AI的6格合并，更不能据此认定火克木或单纯削弱木修。初次未冻结诊断12场不计入正式60场和分母；历史12条引用新增执行0。

本次战斗规则、默认配装和AI核心文件保持v0.15.3，原[完整12×12表](balance/cleanse-v0153/final/report.md)继续有效。页面版本升为0.15.4表示教学界面更新；规则标签仍为v0.15.3-cleanse。极端配对尚未解决。后续优先在同一公开局面复查对手如何分配准备、兑现与回复，以合法费用和明确预告验证分级决策。
