# 净化与恢复复查 · v0.15.3

最终保留净息的8点回复，但需要自身有灼烧：花1行动与1任意灵气，清尽自身灼烧并恢复至多8气血。无灼烧时不可用，不能再同一回合连续把通用净化当作24点恢复。涤尘维持1行动、1水气、18回复、每回合一次，清烧上限由5层改为1层；水修首次主动付费水法仍另外清1层，因此新阶段先用涤尘最多共清2层。清尽高层灼烧仍需另付净息的行动与灵气。

涤尘更偏恢复，净息更偏清尽高层灼烧；两者不再同时提供同等净化强度，水修需要在回血量、剩余层数、行动和水气之间选择。

其他神通的伤害、费用、防御、射程、五行、十二套新招六槽及搜索预算保持上一版。净息·凝滞仍只清凝滞并回8气血；寄生净化和准备破除继续各自付费。回顾按神通实际参数统计净息回复，避免既读技能回复又额外叠加通用8点。

## 筛选与被否定的方案

旧净息可以无灼烧连续使用，同一回合3行动、3任意灵气便能回24气血。[手动旧版实测](balance/cleanse-v0153/choices/manual-baseline.json)从100到124。自动策略本来过滤空净息；加入真实合法性条件主要修正手动操作，不能把它说成已经提高AI胜率。

净息回复分别测试4与0。取消回复的全对手隔离确认中，烈焰筹划27→34胜/66，共生0→5胜/6；寄生仍0/6。引燃筹划36→40、焚灼32→43，表明灼烧套路普遍受益。随后与涤尘清1层同时采用，另完整测试936场均衡、468场稳守：烈焰35/66，但共生34→26、寄生25→20、寒凝36→30胜/66，筹划总体范围从36.4%–63.6%扩大为30.3%–65.2%。因此**不采用取消净息回复**，不能只看烈焰一行的改善。[未采用组合12×12](balance/cleanse-v0153/combined-zero/report.md)／[逐项对照](balance/cleanse-v0153/combined-zero-comparison.md)。

涤尘回复减到14或12也不采用：独立全对手确认中，潮汐筹划34→24／21胜/66，寒凝36→27／28，范围削弱过大。保留18回复、仅限制清烧，更直接影响灼烧对局而保留其他对局的恢复能力。

清烧1／2层各独立测试90场，对引燃、烈焰、焚灼三对手：潮汐稳守17/18→13/18（清1）或17/18（清2）；寒凝筹划17/18→16/18，两候选相同；潮汐筹划10/18→8/18或9/18。选择清1继续完整组合验证。180场局部结果未包含生息和所有非灼烧对手，不能拿局部稳守改善当作全对手结论。

## 决策复盘与额外验证

四个第3回合只读决策片段保存实际候选、预算、选招和预测／实际差异。烈焰对寄生常优先净寄生、防护和恢复，进攻窗口的预测受到对手下一阶段重新选招影响。这是公开主招加备用策略与实际自适应对手的边界，不是浏览器执行公开队列的结算错误；没有依据四点改全局搜索权重。

水修两点沿用稳守即时的实际轨迹，再强制调用筹划评分作诊断，并不是即时AI实际选择的筹划路径。[完整冻结诊断](balance/cleanse-v0153/choices/audit.json)。

零回复组合实现后发现，回顾仍把每次净息计作8点“治疗溢出”。均衡已完成552场时停止、稳守468场已完成，保留这些额外记录；修正后完整重测1404场零回复组合，再依据全矩阵否定它。最终8回复版再次完整新测，回顾既验证受伤时回8／溢出0，也验证满血时回0／溢出8。
