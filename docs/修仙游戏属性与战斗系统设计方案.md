## 一、总体方向与参考取舍

建议采用：**以《觅长生》的五行灵气与功法构筑为基础，加入《太吾绘卷》的距离、出招条件和攻防应对，让境界突破真正改变战斗方式。**

目标是让“修炼什么功法，就以什么方式战斗”，同时保留临场判断，而非完成配装后反复使用同一个技能。

| 参考方向 | 《太吾绘卷》值得借鉴的思路 | 《觅长生》值得借鉴的思路 | 本方案的转化方式 |
| --- | --- | --- | --- |
| 人物成长 | 基础属性、资质、功法与装备共同塑造人物 | 灵根、境界、功法和悟道共同塑造修士 | 区分先天资质、后天属性和修炼成果 |
| 战斗资源 | 出招受到式、提气、架势等条件影响 | 五行灵气影响神通使用与组合 | 五行灵气支付技能，大招增加前置条件 |
| 攻防关系 | 力道、精妙、迅疾等攻击特征有相应应对 | 神通、状态和功法之间形成联动 | 给技能明确的攻击标签和应对方式 |
| 战斗空间 | 武器与功法的距离适性影响发挥 | 更强调资源管理与构筑 | 保留近、中、远三个距离档 |
| 流派特色 | 同类武学可以形成不同战斗风格 | 功法和神通组合产生不同战斗循环 | 每个流派有自己的资源或状态循环 |
| 战斗决策 | 何时接近、出招、运功和防御 | 如何分配灵气、铺垫和爆发 | 同时考虑资源与出手时机 |

### 复杂度控制

不完整叠加两款游戏的全部资源。基础战斗要求玩家持续关注四件事：

- 自己还能承受多少伤害。
- 当前有哪些灵气。
- 本回合还能行动几次。
- 敌人正在准备什么。

剑意、毒、魂印、阵纹等只作为特定流派的附加机制逐步开放。

## 二、人物属性分层

| 层级 | 内容 | 作用 |
| --- | --- | --- |
| 先天资质 | 灵根、功法资质、体质特性 | 决定修炼倾向与成长效率 |
| 基础属性 | 体魄、根骨、身法、神识、悟性、心境 | 描述人物长期能力 |
| 修炼成果 | 境界、功法层数、悟道、本命法宝 | 决定核心玩法与实力上限 |
| 战斗属性 | 气血、伤害、防御、纳气、先手等 | 直接用于战斗计算 |

角色示例：

> 火木双灵根，体魄一般，神识较强，悟性出众；主修火法，辅修木系生息功，以木系状态铺垫火系爆发。

角色需要具有清晰的身份，让玩家能理解选择某种功法与成长路线的原因。

## 三、基础属性

建议使用六项基础属性，每项拥有明确职责。

| 属性 | 修仙含义 | 战斗作用 | 非战斗作用 | 设计注意 |
| --- | --- | --- | --- | --- |
| 体魄 | 肉身强度、气血旺盛程度 | 提高气血、体修伤害与肉身防御 | 承受环境伤害、炼体、劳动 | 不同时大幅提高所有伤害 |
| 根骨 | 经脉、丹田与承载灵力的能力 | 提高灵气容量，满足部分功法承载要求 | 筑基品质、经脉修炼 | 与灵根区分，不等于五行资质 |
| 身法 | 移动、姿态调整与反应能力 | 提高先手，强化移动与特定闪避效果 | 潜行、逃脱、探索危险地形 | 不直接增加完整行动次数 |
| 神识 | 感知、操控和精神强度 | 强化御器、神魂攻击与多目标操控 | 探查、炼器、识破伪装 | 避免同时统治法术、命中和防御 |
| 悟性 | 理解功法与推演道理的能力 | 通过功法领悟间接强化战斗 | 学习速度、悟道、改良神通 | 避免直接乘算全部战斗伤害 |
| 心境 | 意志稳定与道心坚定程度 | 抵抗恐惧、幻惑、反噬，维持蓄势 | 心魔、突破、特殊剧情选择 | 需要实际事件支撑，不只是突破门槛 |

### 职责边界

**根骨管承载，灵根管五行亲和。**高根骨修士可以容纳更多灵气；高火灵根修士更适合凝聚和运用火灵气。

**悟性管学习，神识管操控。**悟性高，学习御剑术更快；神识高，更容易控制复杂的飞剑攻击。

若希望保留更细的肉身差异，可以增加“膂力”，将体魄拆成力量与体质。初版六项足够，不建议只为丰富面板而增加属性。

## 四、灵根与功法资质

### 灵根结构

| 部分 | 含义 | 示例 |
| --- | --- | --- |
| 五行亲和 | 各属性的修炼效率与灵气配置倾向 | 火亲和高，木亲和中，其他较低 |
| 灵根特性 | 改变资源规则的特殊天赋 | 火灵气储存上限提高，相生转化获得额外收益 |

不同灵根形成不同优势：

- **单灵根**：主属性灵气稳定，专精功法成型快；跨属性组合需要额外手段。
- **双灵根**：适合相生联动，稳定支持两种功法。
- **多灵根**：学习成本较高，但混合神通、转化功法和阵法选择更多。

可以保留传统设定中单灵根修炼更快的优势，但不必同时给予全面的战斗效率优势，避免其他灵根只能承担困难模式。

### 功法资质

初版设置剑道、体修、术法、御器、神魂、阵法六类即可。

资质主要影响学习时间、领悟难度与熟练度增长，不建议直接作为永久伤害乘区。通过师承、顿悟、特殊修炼与洗髓，允许后天补足短板。

炼丹、炼器、符箓等生活技能独立成长，不全部混进基础属性。

## 五、战斗属性

| 类别 | 属性 | 用途 |
| --- | --- | --- |
| 生存 | 气血上限 | 承受伤害 |
| 生存 | 肉身防御 | 抵御物理、兵刃与体术伤害 |
| 生存 | 灵力防御 | 抵御元素、一般法术及基础神魂伤害 |
| 生存 | 心神抗性 | 抵抗神魂伤害附带的精神异常 |
| 资源 | 灵气容量 | 当前可储存的灵气总量 |
| 资源 | 纳气量 | 每回合获得多少灵气 |
| 资源 | 灵气配置 | 获得的灵气分别是什么属性 |
| 输出 | 体术威力 | 强化拳脚、肉身与部分近战技能 |
| 输出 | 术法威力 | 强化一般法术 |
| 输出 | 御器威力 | 强化飞剑与法宝主动攻击 |
| 输出 | 神魂威力 | 强化神识攻击与精神类神通 |
| 输出 | 破甲／破法 | 削弱对应防御 |
| 节奏 | 先手 | 影响行动顺序 |
| 状态 | 异常强度 | 强化灼烧、毒、魂印等效果 |
| 状态 | 异常抗性 | 缩短或削弱异常效果 |

角色无需同时发展四种输出属性。面板优先展示当前流派使用的属性，其余放进详细信息。

### 谨慎加入的属性

- **命中与闪避**：基础攻击尽量可靠，闪避更多通过主动技能实现。避免高消耗大招因随机落空而失去策略反馈。
- **暴击**：可保留，但不成为所有流派的共同最优选择。剑修可以靠识破破绽获得确定暴击。
- **速度**：用于先手与部分移动收益，不让角色连续获得多个完整回合。
- **吸血**：优先作为血修、魔功的特殊机制，避免成为所有流派的通用生存解法。

## 六、战斗资源

采用**五行灵气池＋行动点**，不额外叠加用途相同的蓝条。

五行灵气就是当前可用于施法的法力。面板可显示“法力 7/10”，展开后显示金、木、水、火、土及通灵的具体数量。

| 项目 | 原型规则 |
| --- | --- |
| 行动点 | 每个角色每回合 3 点，不跨回合保留 |
| 纳气量 | 每回合开始获得 5 点灵气 |
| 灵气容量 | 总容量 10 点，未使用的灵气保留 |
| 应对次数 | 每个角色每回合最多 1 次 |
| 普通技能 | 通常消耗 1 行动点 |
| 强力技能 | 消耗 2 行动点，或需要蓄势 |
| 基础攻击 | 消耗行动点，不消耗灵气 |
| 普通移动 | 消耗 1 行动点，默认不消耗灵气 |
| 主动调息 | 消耗行动点，获得少量灵气，每回合限一次 |

行动点决定本回合能做多少事，五行灵气决定能做哪些事。

### 技能费用示例

- **焚炎术**：1 行动点，2 火灵气＋1 任意灵气。
- **御木诀**：应对技能，消耗 1 木灵气，生成临时护盾；不占普通行动点，受每回合应对次数限制。

少量“通灵”资源可以支付任意灵气费用，但不能直接替代指定属性费用。普通五行灵气也可以支付任意费用。

### 灵气生成

以可规划为主。例如火木修士每回合稳定获得 2 火、2 木、1 通灵。

若需要随机变化，可以只随机其中少量灵气，并提供转化手段，不将整回合能否行动交给随机抽取。

容量不足时应允许玩家选择保留哪些灵气，或设置可编辑的保留优先级，避免系统自动丢掉关键资源。

### 循环约束

免费转化、灵气返还与触发技能设置次数限制。明确哪些效果可以互相触发，防止出现无限循环。

## 七、回合流程与应对

### 完整回合

1. **回合开始**：双方纳气，处理到期状态与回合开始效果，恢复应对次数。
2. **意图展示**：显示敌人的重要动作，例如蓄势、突进或治疗。
3. **确定先后手**：依据先手属性安排双方行动阶段。
4. **角色行动**：每方使用 3 点行动点，安排攻击、移动、调息、净化等。
5. **即时应对**：攻击触发应对条件时，受击方在伤害或效果生效前选择应对。
6. **回合结束**：处理状态衰减、临时效果与战场变化。

每个效果指定唯一结算时点，避免回合开始与角色行动开始重复结算。

### 应对类型

| 应对方式 | 适合处理的攻击 | 代价或限制 |
| --- | --- | --- |
| 护体 | 一般直接伤害 | 消耗灵气，可能被破盾攻击克制 |
| 格挡 | 兵刃、体术、多段攻击 | 需要相应武器或功法 |
| 闪身 | 单次攻击、部分范围攻击 | 需要移动空间，可能改变距离 |
| 反制 | 可以被干扰的施法 | 对快速技能无效 |
| 镇心 | 恐惧、幻惑、魂印等 | 对肉身伤害帮助有限 |

每回合只有一次应对，形成“现在挡住普通攻击，还是留下机会处理重击”的取舍。

### 蓄势与打断

蓄势技能需要给对手实际的处理时间：本次行动支付费用并开始蓄势，在施法者下一次行动阶段开始时释放。对手可以打断、拉开距离、准备护盾或施加减伤。

技能说明应写清：

- 是否可以被打断。
- 打断条件是什么。
- 打断后取消、降级释放还是返还部分灵气。
- 目标离开范围后如何处理。

公开规则，不让玩家只能依赖试错。

## 八、距离与攻防匹配

### 三档距离

| 距离 | 典型优势 | 典型限制 |
| --- | --- | --- |
| 近身 | 体修、短兵、擒拿、近距离爆发 | 更容易受到反击 |
| 中距 | 飞剑、常规法术、攻守转换 | 优势较均衡 |
| 远距 | 蓄势、远程术法、部分法宝 | 容易被突进或遮蔽视线影响 |

普通移动消耗 1 行动点，改变一个距离档。

不同技能以不同方式受到距离影响：

- 拳法远距不可用，可以搭配突进。
- 飞剑近距仍能攻击，部分剑法效果变化。
- 远程蓄势法术近身释放更容易被打断。
- 神魂术通常不受普通距离影响，但受到遮蔽神识的效果限制。

初版按单人斗法设计距离；扩展多人战斗时，应先确定采用站位还是目标间距离，不能直接沿用一个全场共享距离。

### 攻击标签

第一版通过技能标签实现攻防匹配，无需先建立多组常驻对抗数值。

| 攻击标签 | 战术特点 | 合适应对 |
| --- | --- | --- |
| 重击 | 单次伤害高、容易破盾 | 闪身、打断蓄势 |
| 连击 | 多段攻击、适合叠加状态 | 格挡、逐段减伤 |
| 精准 | 突破部分常规防御 | 遮蔽、扰乱锁定 |
| 术法 | 灵气驱动，可被部分反制 | 灵盾、反制 |
| 神魂 | 攻击心神，附带精神状态 | 镇心、神魂防护 |

技能可以同时拥有“术法＋重击＋蓄势”等标签，让玩家推断应对方式。

## 九、五行机制

重点体现战斗风格，相生相克作用于具体机制。

| 属性 | 战斗身份 | 常见机制 |
| --- | --- | --- |
| 金 | 精准、穿透、锋锐 | 破甲、剑气、标记、多段斩击 |
| 木 | 生长、持续、寄生 | 治疗、毒、种子、灵植、缠绕 |
| 水 | 调节、控制、柔化 | 凝滞、净化、资源转化、削弱 |
| 火 | 爆发、扩散、燃烧 | 灼烧、引爆、过热、范围伤害 |
| 土 | 稳固、防护、镇压 | 护盾、壁垒、反震、限制移动 |

五行亲和与攻击类型分开。金系可以是飞剑，也可以是金行术法；火系体修可以使用带火属性的拳法。

### 相生联动

- **木生火**：木系种子被火法引燃，增加爆发。
- **火生土**：燃烧留下灰烬，土系技能转化为护盾。
- **土生金**：土系镇压制造破绽，金系攻击获得穿透。
- **金生水**：金系标记帮助水系神通锁定或回收资源。
- **水生木**：水系滋养延长灵植或恢复效果。

### 相克互动

- 水系净化削弱灼烧。
- 金系斩断木系缠绕。
- 木系寄生持续侵蚀土盾。
- 火系高温削弱某些金属防护。
- 土系镇定抵抗水系推动与牵引。

这些是玩法化设计，可以按世界观调整。不建议仅设置固定的大幅属性克制增伤，否则换属性会取代功法组合与临场操作。

雷、冰、风、阴阳等作为进阶分支开放，初版不必全部建立独立资源池。

## 十、功法、神通与法宝

| 系统 | 主要作用 | 示例 |
| --- | --- | --- |
| 主修功法 | 决定核心循环与资源规则 | 火灵气达到一定数量时，第一次火法强化 |
| 辅修功法 | 补足短板、增加联动 | 消耗木灵气施法后，下一次火法增强 |
| 神通 | 执行具体战斗动作 | 攻击、治疗、移动、净化、蓄势 |
| 悟道 | 改变机制与流派分支 | 灼烧侧重持续伤害，或侧重引爆 |
| 法宝 | 提供特殊能力和战术补充 | 护盾、打断、储气、范围攻击 |
| 本命法宝 | 随角色成长的长期核心 | 飞剑、丹炉、魂幡、阵盘 |

### 初版装备上限

- 1 部主修功法。
- 2 部辅修功法。
- 6 个主动神通。
- 2 个应对神通。
- 1 件本命法宝。
- 2 件普通法宝。

控制技能数量，通过机制联动产生组合空间。

### 神通分支示例：御剑术

| 分支 | 改变 |
| --- | --- |
| 快剑 | 消耗低，适合频繁攻击与叠加剑意 |
| 重剑 | 消耗高，擅长破盾与蓄势爆发 |
| 飞剑 | 距离适性好，可以改变攻击目标 |
| 心剑 | 部分效果作用于神魂，擅长识破与反制 |

### 功法成长

| 阶段 | 变化 |
| --- | --- |
| 入门 | 获得基础效果 |
| 小成 | 减少费用或改善使用条件 |
| 大成 | 解锁机制分支 |
| 圆满 | 强化核心循环 |
| 真意 | 改变关键规则，同时付出代价 |

例如允许以气血替代部分火灵气费用，形成血火流，而不是只增加全局伤害。

## 十一、流派构筑

| 流派 | 核心循环 | 优势 | 弱点 |
| --- | --- | --- | --- |
| 剑修 | 攻击积累剑意 → 识破 → 爆发 | 精准、破甲、单体强 | 怕剑意被打断或爆发被化解 |
| 火法 | 灼烧铺垫 → 扩散或引爆 | 爆发、群攻 | 怕净化，资源投入较大 |
| 水法 | 凝滞 → 灵气调节 → 持续控制 | 应对灵活、资源稳定 | 即时击杀能力较弱 |
| 木修 | 种子／灵植 → 生长 → 治疗或寄生 | 续航、长期收益 | 怕快速爆发和清除场上单位 |
| 土修 | 护盾 → 稳固 → 反震或镇压 | 防护、阵地战 | 怕穿透和持续侵蚀 |
| 体修 | 近身 → 积势 → 重击 | 灵气依赖低、近身强 | 怕拉开距离和限制移动 |
| 神魂修 | 魂印 → 扰乱 → 引爆 | 干扰施法、攻击特殊目标 | 怕镇心，对无心智敌人需替代打法 |
| 阵修 | 布置阵纹 → 连接 → 阵法运转 | 场面控制、长期收益 | 起手慢，阵眼可被破坏 |

每个流派至少需要：

1. 低成本启动手段。
2. 维持循环的办法。
3. 明确的收益兑现方式。
4. 防守或补救选择。
5. 敌人可以利用的弱点。

混合流派连接两种循环。例如火木修通过木系铺种子、火系选择引爆时机形成玩法，而不只是同时装备火球和治疗。

## 十二、状态系统

| 状态 | 建议规则 | 战术意义 |
| --- | --- | --- |
| 灼烧 | 有层数和剩余时间，可被引爆 | 持续伤害与爆发之间取舍 |
| 中毒 | 层数逐渐增长，可被净化 | 迫使对手处理长期威胁 |
| 破绽 | 下一次指定攻击获得强化，触发后消失 | 创造攻击窗口 |
| 凝滞 | 增加移动代价或削弱特定行动 | 控制距离与节奏 |
| 缠绕 | 限制移动，可通过动作挣脱 | 配合远程或阵地打法 |
| 魂印 | 达到条件后触发精神效果 | 神魂流铺垫 |
| 稳固 | 减少位移，提高抗打断能力 | 保护蓄势与阵地 |
| 反噬 | 强行施法产生自损 | 为高风险爆发提供代价 |

### 状态说明要求

所有状态写清结算时点、层数上限、重复施加规则、持续时间和清除方式。

灼烧规则示例：

> 上限 5 层，每层持续 3 回合；重复施加增加层数并刷新持续时间；目标行动阶段开始时结算；引爆消耗所有层数。持续时间的递减时点统一写入系统规则。

### 控制限制

眩晕、冻结和完全封禁施法不应反复无缝衔接。优先采用局部限制：不能移动、下一次术法费用增加、蓄势效率下降等。

Boss 可以拥有更高控制阈值，但不对全部状态免疫，避免控制、毒和魂印流派失效。

## 十三、伤害公式与数值约束

### 基础公式

```text
基础伤害 = 技能固定值 + 对应威力 × 技能系数

有效防御 = max(0, 防御 × (1 - 百分比穿透) - 固定穿透)

防御后伤害 = 基础伤害 × K / (K + 有效防御)

最终伤害 = 防御后伤害 × 技能条件倍率 × 其他明确修正
```

- K 为防御尺度，初期测试可取 100。
- 有效防御为 100、K 为 100 时，伤害减半。
- 数值随境界大幅增长时，K 按明确的战斗尺度规则调整。
- 护盾在伤害计算后吸收伤害，剩余部分扣除气血。
- 明确最终取整规则，避免多段攻击因重复取整产生意外差异。

### 计算示例

焚炎术基础伤害 60；引燃种子获得 40% 增伤；敌人有效灵防 100；K＝100。

```text
60 × 1.4 × 100 / (100 + 100) = 42
```

敌人剩余护盾为 15：

```text
护盾吸收 15，气血受到 27 点伤害。
```

### 平衡约束

同类别增伤通常加算，再与少量不同机制相乘。限制独立乘区数量，避免功法、法宝、悟道、元素和状态增伤全部乘算后失控。

百分比穿透、减伤和异常效果需要明确上限。不要通过堆叠常见属性轻易形成完全免伤或永久控制。

神魂伤害不天然无视全部防御：基础伤害经过灵力防御，心神抗性处理精神异常。需要绕过护盾的神通单独说明，并付出费用或威力代价。

## 十四、境界成长

| 境界 | 建议开放的变化 |
| --- | --- |
| 炼气 | 基础灵气配置、五行神通、简单应对 |
| 筑基 | 主修路线、功法分支、筑基特性 |
| 金丹 | 金丹特性、本命法宝核心能力 |
| 元婴 | 元婴保命、神魂延伸、有限分身 |
| 化神 | 领域，改变局部战场规则 |
| 更高境界 | 围绕道则和条件改写深化玩法 |

### 成长原则

不在每次突破时同时增加行动点、纳气量、灵气容量和全部伤害，避免后期连续释放大量技能，破坏资源取舍。

更适合的成长方式：

- 容量逐渐提高，允许更长铺垫。
- 技能效率适度提高。
- 解锁转化与联动。
- 增加战术选择。
- 保持行动次数相对稳定。

### 境界压制

通过属性、功法完成度和高阶机制体现压制。低境界修士可依靠准备与针对性挑战高一小阶的敌人；跨越大境界需要特殊条件，例如破坏阵眼、借助法宝或完成逃脱目标。

### 战败与寿元

气血耗尽后的结果由场景决定：切磋认输、普通斗法重伤、死斗死亡，或触发元婴逃遁。

寿元主要用于长期修炼与探索，不作为全部战斗技能的常规消耗；燃烧寿元应属于少数高风险神通。

## 十五、敌人、界面与战斗外成长

### 敌人行为

| 敌人 | 行为特点 | 玩家主要决策 |
| --- | --- | --- |
| 剑修 | 寻找破绽，积累剑意后爆发 | 防守时机、打断时机 |
| 体修 | 突进、近身、重击 | 管理距离 |
| 火修 | 灼烧铺垫后引爆 | 净化与护盾时机 |
| 阵修 | 布阵、保护阵眼 | 攻击本体还是破坏阵眼 |
| 妖兽 | 明显蓄势、扑击与阶段变化 | 观察动作，利用攻击窗口 |
| 邪修 | 吸血、献祭、魂印 | 处理附属单位还是压制本体 |

重要敌人动作公开预告，已经承诺的蓄势技能不能随意改变规则。普通攻击的细节可以保留不确定性。

### 界面要求

- 显示五行灵气具体数量。
- 显示剩余行动点与应对次数。
- 显示当前距离。
- 显示主要状态层数、持续时间与结算时机。
- 显示敌人的重要蓄势动作。
- 提供技能预计伤害及主要修正来源。

### 战斗外成长

功法获取连接宗门、师承、探索、论道与遗迹。

- 丹药：有限恢复与修炼辅助。
- 符箓：一次性战术补充。
- 炼器：法宝定向改造。
- 闭关：功法熟练、悟道与境界进度。
- 论道：解锁机制理解、分支与流派补强。

消耗品设置使用次数、行动代价或携带限制，避免战斗只比较库存。

## 十六、首版原型与战斗示例

### 原型范围

| 内容 | 范围 |
| --- | --- |
| 战斗规模 | 1 对 1 |
| 流派 | 剑修、火木法修、体修、土修 |
| 神通 | 每流派 5～6 个 |
| 功法 | 每流派 1 部主修、2 部可选辅修 |
| 距离 | 近、中、远 |
| 核心状态 | 剑意、破绽、种子、灼烧、护盾、稳固 |
| 敌人 | 约 8 种，包括 2 个有阶段变化的 Boss |
| 境界 | 炼气、筑基 |

### 火木修回合示例

假设本回合获得 2 火、2 木、1 通灵，共 5 点灵气，拥有 3 点行动点；此前没有储存灵气。

| 步骤 | 动作 | 行动点消耗 | 灵气消耗 | 剩余灵气 | 效果 |
| --- | --- | --- | --- | --- | --- |
| 1 | 催生术 | 1 | 1 木 | 2 火、1 木、1 通灵 | 给敌人种下两层种子 |
| 2 | 焚炎术 | 1 | 2 火、1 通灵 | 1 木 | 引燃种子，造成强化伤害 |
| 3 | 拉开距离 | 1 | 无 | 1 木 | 距离增加一档 |
| 敌方攻击时 | 御木诀 | 不消耗普通行动点 | 1 木 | 无 | 消耗本回合应对次数，生成临时护盾 |

如果敌人正在准备远程蓄势攻击，第三行动可以改为干扰；如果敌人有反制机会，可以先用低成本神通试探；如果准备下回合爆发，可以暂时不引燃种子。

### 原型验收重点

1. 玩家是否有理由改变出招顺序。
2. 不同敌人是否能改变玩家决策。
3. 不同流派是否拥有不同资源循环。
4. 战败后能否理解判断失误的原因。
5. 是否存在固定顺序的无脑最优解。
6. 是否存在无限返还、永久控制或完全免伤组合。
7. 面板与战斗记录是否足以解释结果。

验证基础循环后，再增加元婴、领域、队友、复杂阵法与更多属性。
