# 青霄论道 · 射程与接近成本修订

日期：2026-10-02。采用单张神通的射程调整：焚炎术限近身 / 中距；催生术、流火诀、星火引仍可远距使用，离火焚天仍限中远距。火木仍能在远处铺垫与施加灼烧，集中引燃爆发需要保持近中距。

## 本轮范围

只比较射程与接近成本；伤害、灵气费用、行动基础费用、回气、灼烧与主修数值保持原样。生息奖励仍为 2，回春基础恢复仍为 18。除实验性的接近返还候选之外，不添加行动奖励；先手补偿未加入。线上自动控制器保持原文件内容。

## 控制器与预测偏差

额外用推荐配置、双方均衡、三距离、交换先手，对原版和采用值各测 96 场。即时回合控制器仍搜索本回合动作组合，沿用相同倾向权重、行动过滤和应对规则，只把行动评分的敌方阶段预测去掉；它不是最优控制器，也不是对所有策略的验证。
