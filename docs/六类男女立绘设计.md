# 六类角色 · 男女立绘与动作设计

日期：2026-10-03。覆盖剑修、火木、离火、水、木、土，男女各一张，共十二张新立绘。沿用国风半写实绘画质感，重新设计动作，并调整脸型、发型和衣着，不以同一站姿换色来区别角色。

## 动作安排

| 流派 | 男版 | 女版 | 轮廓与动势的区别 |
| --- | --- | --- | --- |
| 剑修 | 前跨弓步，身体略俯，单剑斜劈，空手后收 | 侧身小步收势，两手贴腰将剑归鞘 | 男版开放斜线进攻；女版收拢纵线、出剑后的余势 |
| 火木 | 侧踏读竹简，一臂横引幼苗上的细火 | 转身持枝杖，掌心向下撒灵种，火星沿种子轨迹 | 男版引燃与研习；女版播种、旋转与轻步 |
| 离火 | 低重心半蹲，单掌前推，另一拳收腰 | 单臂上举引焰，另一手贴胸掐诀，错步半转身 | 男版横向冲击；女版纵向扬焰 |
| 水 | 向后退步，一手近胸持冰扇，另一手低位牵流 | 侧踏旋身，单臂划护身潮弧，另一手贴肩结印 | 男版柔化、后引；女版圆弧转势、御潮 |
| 木 | 微屈半蹲，两手收拢照料手中小灵植 | 前脚斜跨、腰身扭转，高低手引紫脉藤 | 男版低位培育；女版高位驭藤、主动施压 |
| 土 | 宽稳站姿，前臂横胸护岩壁，另一掌低压结印 | 直立错步，一手持石杖定势，另一手斜上令悬岩 | 男版承压守御；女版立势镇岳 |

衣着遵循流派主色：剑为白银与墨青，火木为绿铜与暖米，离火为赤红与炭黑，水为冰蓝与深靛，木为竹青与灰褐，土为赭黄与岩灰。性别不绑定主修、数值或技能；两个版本都可以表现本派任一主修。

## 制作与接入约束

- 十二张均为 1024 × 1536 RGBA 原图，带透明区域与半透明元素柔光。头饰、衣摆、武器没有被画布裁切；木修男版的后脚被衣摆遮住。
- 主动作大体朝右，允许侧身、转体、前倾与收势；对手位可镜像，受击位移独立于朝向。
- 让动作区别来自重心、步态、手臂位置与武器方向；既有元素装饰不能成为所有人的同一个双掌摊开模板。
- 元素效果围绕人物，柔光不代表真实射程。接入时按实际主体占比调整显示大小，人物与血条、文字区域各自独立。
- 本次为美术设计与审阅，不改变战斗数值或在游戏中提前实现水、木、土。性别选择入口在实际接入阶段处理。

当前这批仍偏华丽长袍和高束发，水、木女版的潮弧与藤弧较宽。后续接入战斗时应根据主体轮廓留出空间；若继续细化美术，可以再增加短衣、散发等服饰与发型变化。
