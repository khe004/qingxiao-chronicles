# 当前十二流派完整配对复查

查看 [分块胜率表、总胜率和镜像先后手](report.md)。可下载 [准备预测矩阵 CSV](matrix-prepared.csv) 和 [即时评分矩阵 CSV](matrix-immediate.csv)。

本次测量使用当前 v0.12 的数值规则，没有修改技能、配装推荐或自动决策。两种控制器共 936 场：每种 396 场不同流派对战、72 场同流派镜像。每对流派使用推荐六槽，近、中、远三种开局距离各交换先手，均衡倾向，30 回合上限；全部分出胜负。

在这组固定 AI 场景中，水、木、土的六个主修，对火木、剑、离火的六个主修，两种控制器合计 432 场全部落败。准备预测控制器下，藏锋重剑跨流派胜率 61/66（92.4%），壁垒守御 7/66（10.6%）。这说明现有规则和 AI 组合存在明显的强度断层，尚不能称为平衡；不能把这些比例当作真人胜率。

每格只有六个确定性场景，不是六次独立随机抽样。两种控制器分别列出，不混合平均；同主修镜像不计入总体排名，对角线空置，先后手结果另列。

## 核对

- 936 个场景均唯一，完整覆盖两种控制器、十二主修、三种距离和双方先手。
- 从逐场记录独立重算所有矩阵格、胜负未决数和每流派 66 场的总胜率，全部一致。
- 当前冻结源码全部通过 SHA-256 校验。
- 上一轮基线 108 场，在新数据中胜负、回合、气血、动作统计和完整纪要全部一致。
- 十二主修各选一场，从冻结源码重新模拟，覆盖所有距离与双方先手；胜负、末态、统计和完整纪要全部一致。
- `test-predictive-arena.mjs`、`test-balance-harness.mjs`、`test-prepared-ai.mjs` 通过。

## 复现

```sh
node scripts/check-twelve-school.mjs /tmp/qingxiao-twelve-school
```

`records.json.gz` 保存全部对局结果、动作统计和完整纪要；`summary.json` 保存配装、场景口径和所有格的胜负未决场数；`source/` 和 `source-hashes.json` 保存冻结测量源码及校验值。

`checkpoint.json.gz` 是同一批完整原始记录的导出恢复点。若本地导出中断，可在该结果目录执行 `node scripts/check-twelve-school.mjs docs/balance/twelve-school-v012 --resume`，不会重跑对局，且会核对模拟规则未变。
