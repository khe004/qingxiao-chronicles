# 木修反制推演 · v0.15.6

本轮修正问道推演对木修准备反制和公开备用招的遗漏。职业数值、招式、双方六槽、行动点、纳气、实战应对和备用策略保持原规则。

## 同局面的修正依据

- 生长被完全破除会取消待成熟。攻势与完整反制假设现在按NPC已有的生长／待成熟估值计入玩家的付费破除；不是凭空减少NPC的准备。
- 目标可花1行动、1灵气单独清寄生；推演计入这条合法出口。寄生侵蚀伤害仍由真实引擎结算，不额外重复记伤害。
- 候选固定队列按真实enemyStep推进，使用该候选预告与剩余队列；破除或距离变化后的接近、补气、替换招式及应对按真实规则付费。阶段结束后停止，下一阶段由原有限反制假设推进。
- 有可选主招时不采用空预告。算入备用招后，空路径会因少量路径成本优势隐藏所有动作；首个候选因此未通过原木土回归，已保留并放弃。可用动作全无时仍允许等待。

7个手动夹具保留同输入与完整字段：四项策略假设原先漏选合法破除／净化，一项完整阶段原先漏执行备用招；采用版均与声明的付费反制或真实阶段参照吻合。两项单行动退距对照不会同时获得免费净化或破除。见before/audit.json与after/audit.json。595个完整敌方阶段对照另见test-wood-counterplay.mjs，不并入胜率分母。

## 公开预测的边界

搜索深度、木土24状态宽度和短名单不变。玩家压迫与反制是公开棋面的有限假设，不读取真人下一步。第一层玩家压迫仍使用规划开始时的公开队列；候选敌方执行及其后续反制使用候选队列。下一回合公开棋面采用基础引擎规划近似，未递归生成新的问道计划。变化修复已确认的推演误差，但不保证最优选择或每位NPC均增强。

采用依据是四个反制估值遗漏、一项完整阶段执行遗漏和完整阶段一致性，而非筛选一个更高胜率。原v0.15.3独立双AI的12×12数据与战斗规则沿用，烈焰双筹划弱格仍未解决。下一轮先看共生／寄生面对不同玩家打法的预告兑现率，再考虑明确的性格或配装变化。
