# 十二流派两两胜率（冻结规则见 source/dist/rules.mjs）

每对流派按 近／中／远 距离交换先后手，共 6 场；原推荐六槽、balanced 倾向、30 回合上限。行对列表示行流派的获胜比例，未决也计入分母。对角线用 —，镜像先手率另列。

这是确定性 AI 固定场景结果，不是真人胜率，也不是随机重复抽样。准备预测边界采用主招与公开备用策略，实际对手会重新选择。数值格局与 AI 使用功法的能力共同影响结果。
此矩阵已完整执行936场。随后仅修订新招样例定义；原推荐的规则和配置未变，因此刷新源码快照时复用936场已测记录，不算新增对局。
