# 问道应对预算 · v0.15.5

修正问道规划中的应对预算和结算顺序。没有增加气血、伤害、行动点或纳气，也没有改对手的六招配置。切磋仍按原性格脚本；两档都在玩家行动前公开固定主招，实战沿用同一备用策略。

## 规划范围与限制

NPC护盾、闪身、致命保命、稳固与预告留气按实战策略执行。玩家侧使用均衡合法应对作为估量，并保留一种可支付的闪身／退距情景；这是公开状态的有限假设，不读取玩家下一步输入，也不保证预测真人打法。付费寄生侵蚀在攻击应对前完成，免费蓄势释放也使用实际应对窗口。

三层搜索、木土24状态宽度、原短名单与评分权重保持不变。缓存包含公开主招／剩余队列；重复读取已经公布的同一计划保持冻结。更多招式预算估量可能使某个对手承伤或改为直接进攻，并不保证每位NPC更难。

本次仍保留原v0.15.3战斗规则和独立双AI 12×12表；改动集中于问道规划，不能据此声称烈焰双筹划弱格修复或整体平衡完成。后续应分别复查指定NPC的准备兑现比例、真人反制和难度差异。
