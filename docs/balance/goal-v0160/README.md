## 筛选中确认的限制

- 留气评分实验 `.65` 未改善剑修弱势，单因素复核也恶化多个对阵，已弃用。
- 降低土修反震次数和伤害会破坏其对重剑、引燃和烈焰的守御能力，已弃用。
- 只提高寄生收获早期伤害没有打破快剑对寄生的全胜局面。
- 净寄生改为两点任意气能够打破部分旧锁，但会增强木修，必须与其他调整一起完整验收。
- 补偿盾为 8 的 H 候选先手指标通过，但还有 6 组一方全败，潮汐主表仅 25/66 胜，凝寒与焚灼合并偏强。
- 剑修回气改为 4 金 + 1 水的方案已被完整 I 表否决；恢复原有三金、一水、一通灵的五气收入。

## 复现与审计

候选参数见 `candidates/*.json`。原始战斗源码保存于 `base/source`，基准提交与逐文件哈希见 `base/metadata.json`；已验证从该基准重建Q与九份战斗源码及规则完全相同。采用新规则后，构建器自动使用此冻结基准，拒绝基准哈希损坏。使用 `node scripts/balance-candidate.mjs 参数文件 /tmp/隔离运行目录` 建立运行目录后，在该目录运行对应测量脚本。每份结果都包含冻结源码、SHA-256、完整配置、先后手、初始距离及逐招纪要。完整候选用 `balance-gates.mjs` 从原始记录重新验收；它同时拒绝重复/缺失场景、非均衡倾向、配置错位及冻结源码损坏。

有限确定性 AI 场景不等于真人概率，也不能证明所有自选配装都已平衡。只有通过均衡矩阵、强攻/稳守复核、针对性反制与真实对局回归后，才采用新规则。
