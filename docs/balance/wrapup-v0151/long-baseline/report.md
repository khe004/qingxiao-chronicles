# 原稳守长局延长诊断

生息消耗新招样例对灵植共生新招样例，中距、生息先手、双方稳守即时AI；沿用原v0.15冻结源码，观察上限从90延长至260。第197回合生息胜，结束气血210 / 0。一次保留的延长诊断不替换原矩阵30回合未决，也不加入胜率分母；同一情境的重复复现不是额外胜率证据。

第88–90、120、150、190及195–196回合纪要均为：催生→焚炎→流火；木方应对加26护盾、培植加12护盾。木方全回合受到31气血伤害，灵植回春消费1生长恢复22，再净息恢复8，净失1。木方不断提前回血，放弃成熟后的进攻；反复动作没有让气血回到同一数值。

第196回合结束木方剩31。第197回合先承受焚炎6、流火18，剩7；到自身阶段开始再受7灼烧而归零，无法继续培植、回春、净息。因此不能用“每轮最终只掉1血”推算木方还可恢复到最后一滴血：回复要支付行动，并发生在阶段开始伤害之后。

这个具体反例是极慢消耗，不是无限循环；197回合依然是体验问题。它不能证明其他未决局都会结束。没有修改恢复数值、强制超时或暗加伤害；准备成熟与主动出击的取舍仍需在教学、对手配装和控制器预测中处理。
