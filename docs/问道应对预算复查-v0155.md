# 问道应对预算复查 · v0.15.5

本轮完善「切磋／问道」的决策区别，修正问道内部模拟的应对与结算顺序。入口仍在「三场论道」：选择问道，再选路线或单场对手。气血、伤害、六槽、纳气与行动点沿用现有规则，预告仍在你行动前确定。

## 三个具体修正

1. NPC应对现在使用实战的伤害门槛、致命保命与预告预算判断。共生只剩2木气、预告回春需要2木气时，可以承受的小招不会被模拟成“先买护盾再保留完整收获能力”。
2. 土修面对逐浪时，规划允许真实的付费稳固：消费土气、地势与应对机会，保持距离，承受该招伤害。旧模拟会直接补盾并被迫退距。
3. 付费施法触发寄生侵蚀后才处理待应对攻击。如果侵蚀先使施术者认输，攻击取消。旧模拟先结算命中，极端局面甚至会认错胜方。免费蓄势释放也沿用真实应对窗口。

模拟继续使用隔离副本，采用不进入数据克隆的方法，避免预告预算计算复制函数失败。历史日志、累计统计与原局均不改变。玩家应对按均衡策略估量，同时保留合法闪身／退距情景；这些是公开状态的有限假设，不是读取玩家下一步操作。三层、木土24状态宽度、原短名单和评分权重保留。缓存加入公开主招／剩余队列，重复读取已经公布的同一份计划保持冻结。
