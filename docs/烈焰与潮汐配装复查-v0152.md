# 烈焰与潮汐配装复查 · v0.15.2

本轮调整两套新招样例：烈焰的燃血槽换焰海，潮汐的润脉槽换涤尘。技能伤害、治疗、消耗、射程、五行和AI沿用v0.15.1；原推荐与自由配装继续可选。最终组合重新测量，[完整12×12](balance/pressure-v0152/final/report.md)和[稳守表](balance/pressure-v0152/defensive/report.md)均保留每格胜、负、未决，历史文件不覆盖。

## 采用的取舍

烈焰新样例**烈火横流**：炎矢、引焰、烈火、焰海横流、烬火反障、敛焰复元。放弃主动燃血返气，增加有门槛的全距兑现；焰海至少需要2灼烧，花2行动、3火1任意，不能随时当作低耗直伤。近中距仍保留1行动烈火，第二次付费即时火法强化每轮只触发一次。反障最多两次、次阶段到期，敛焰恢复14并占行动和灵气。

潮汐新样例**贯潮涤尘**：玄水矢、纳潮、沧澜击、贯潮长虹、涤尘、御水诀。将原来最多24回血、消耗潮势的润脉，换成固定18回血、清灼烧、不消费潮势的涤尘。少6点峰值恢复，保留进攻准备；御水仍消费潮势，护盾、进攻和应对也争用水气。涤尘不能清寄生。

双方配装、单方配置和费用说明同步更新。存储的旧六招原样保留；旧样例不再匹配新版名称时显示“自选”，不偷偷换招。

## 预测边界复盘

四个只读决策点在第3回合中距，检查选招、固定搜索预算、公开脚本预测与实际重新选招的下一阶段。[冻结结果](balance/pressure-v0152/choices/audit.json)中潮汐对共生一例，预测己方气血192，实际170；其他指定片段有一致或较小差异。这是筹划擂台对自适应对手的假设差异，不是浏览器按已公开队列执行时的结算错误，也不是四点给出的全局误差界。

本轮没有单改离线预测来抬高表格，也没有增加搜索预算；更强预测须另做成对的真实结算验证和运行成本检查。
