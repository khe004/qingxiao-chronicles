# 受击动画与公开计划预测检查

日期：2026-10-02。基于射程修订后的版本；本轮没有调整伤害、费用、回血、主修或自动打法权重。

## 受击动画

剑修作为玩家时，双方立绘用 `scaleX(-1)` 调整朝向；旧受击关键帧又写入 `transform: translateX(...)`，覆盖了镜像。浏览器在这两种变换之间插值，造成受击时反转。

将受击位移改为独立的 CSS `translate` 属性，朝向继续由原来的 `transform` 保持。保留火木对局原有的 0.5 秒节奏、6px / -3px 轻微位移与受击高亮。距离移动、人物尺寸和位置不变。

浏览器实际出招检查覆盖 1440px 和 390px 两种宽度、火木和剑修两种玩家选择、双方立绘，以及每次动画的五个时间点。朝向始终不变；偏移按原关键帧发生并归位。另检查减少动态效果设置、重新开始清理动画和页面无横向溢出。

## 先核对线上公开计划

线上敌人执行已预告的固定队列，距离或资源不够时跳过，不临时换招。自动玩家使用相同的队列估计敌人后续行动。本轮首先确认：这一估计是否和实际结算一致。

预测的结束点是**下一次己方行动开始并完成自动结算**。除了敌方出招，还包括下一回合双方纳气、己方灼烧和免费释放蓄势。死亡时立即停止。应对使用选定的自动倾向；手动玩家若选了不同应对，结果可以不同。

| 检查 | 结果 |
| --- | --- |
| 实际完整对局 | 96 场，均结束 |
| 配置覆盖 | 四个主修的推荐配装；对方两个主修；近、中、远；四种玩家自动倾向 |
| 敌方阶段预测比较 | 340 个片段 |
| 同一结束点的完整战斗状态一致 | 340 / 340 |
| 己方 / 敌方气血平均绝对误差 | 0 / 0 |
| 距离一致 | 340 / 340 |
| 包含距离跳过的片段 | 90 |
| 包含闪身的片段 | 81 |
| 包含蓄势释放的片段 | 76 |
| 敌方行动结束与己方下次开始之间，气血或护盾继续改变 | 145 个片段 |

比较的完整状态包括气血、护盾、六种灵气、行动点、剑意、灵种、灼烧及持续次数、藏锋、主修触发、已用技能、蓄势快照、距离、阶段、待应对攻击、剩余队列和胜负。战斗纪要的数组不参与状态相等断言；预测副本省略旧纪要，避免搜索反复复制历史。

独立边界用例还核对了：拉远后预告焚炎跳过且不扣费；闪身改变后续射程；己方灼烧发生在下一次行动开始；蓄势后的新剑意不追加到已支付的大招；免费释放不二次扣气或行动；近身使蓄势落空；灼烧致死后不继续出招。

**结论：此次覆盖范围内，线上固定公开计划的结算预测正确，未发现需要修改的规则错误。** 这证明模型与规则一致，不证明自动玩家已经会选最好的招，也不是对全部配装和状态的穷举。

## 为什么离线仍有预测偏差

上一轮的对称擂台让对方也使用自动玩家，每次行动都会重新选择招式；预测却依旧使用固定公开脚本。此外，擂台让双方都用自动应对，线上敌人使用自己的应对规则。即使结算引擎一致，假定的敌方行为仍可能不同。

上一轮离线探针已经有意把预测截到敌方行动结束，再与同一时间点的实际结果比较。采用射程修订的 96 个离线片段，己方气血平均绝对误差约 20.75，敌方约 3.92，距离一致 67 / 96；这些差异并未被本次线上检查推翻。**两个报告测量的是不同对手模型：固定预告和逐招重规划。** 不能用本次的零误差宣称离线偏差已修好。

本轮把两个时间点同时保存，防止后续换预测器时混入纳气、灼烧或免费释放的边界差异。双 AI 预测还需要按真实先后手处理跨回合资源：后手结束时，对方下一次行动前可能先纳气，不能套用同回合敌方阶段。
