# 十二流派平衡验收 v0.16

在候选调整前固定以下标准。基线是 `cleanse-v0153/final` 的 936 场；v0.15.7 的 276 场木修兼容复跑未改变该表。

1. 新招示例六槽、均衡倾向、近中远各交换先后手。准备预测 AI 主表的十二流派跨流派胜率均为 40%–60%；两控制器合并也均为 40%–60%。胜率分母包括未决，镜像另计。
2. 每对主修在 immediate / prepared 合计十二场中，双方至少各胜一场；不得用总体平均掩盖全败对阵。单个控制器六场全败另列并测试合法反制配装，不能靠改示例配置隐藏原表。
3. 两个控制器各自的跨流派先手获胜比例 40%–60%，镜像按流派、距离单列。开场补偿的任何修改必须独立核对，不按十二个镜像平均掩盖某流派偏差。
4. 均衡主表未决低于 2%；强攻、稳守复核不出现新的全局优势流派，并检查恢复、护盾、灵气周转拖延。超时未决须延长重放，不能当作战术平局。
5. 五行相克、资源支付、准备收获、打断、应对、近远距等机制可复现；规则与说明同源。真实对局回归及浏览器流程通过后才提交和发布。

报告须提供 12×12 表（可按六列拆分）、逐格场数、先后手、不同控制器与倾向。所有候选保存参数、代码哈希和完整纪要。筛选场景不替代完整矩阵；历史结果不算新增实测。

以上是有限确定性场景的工程验收，不能据此推断真人概率或所有自选配装都已平衡。达到后仍保留更广泛配装与真人验证的范围限制。
