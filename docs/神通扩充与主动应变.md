# v0.14 神通扩充与主动应变

六派各新增四招，神通库由八选六扩为十二选六，共 24 个新增神通。六个装备槽、三行动、灵气容量十点沿用现有规则。「推荐搭配」保持原配置，「新招套路」分别提供十二个可编辑的示例；示例不是最优配装。

| 功法 | 新增神通 | 主要取舍 |
| --- | --- | --- |
| 火木 | 灵芽护身、摄灵回春、千种燎原、青木引火 | 同一灵种用于种灵护体、回血、全距爆发或换气，消费后不能重复兑现 |
| 剑修 | 静心养剑、回锋剑屏、穿甲剑、碎垒重剑 | 无伤养意、一次反击、额外费用换破盾、两行动部分剑意重击 |
| 炎修 | 燃血聚火、烬火反障、敛焰复元、焰海横流 | 损血换气、两次有限反伤、有限清烧与回复、两行动全距灼烧消费 |
| 水修 | 贯潮长虹、玄水镜屏、润脉回潮、碎冰矢 | 潮势攻击／反击／回复共用；凝滞用于碎冰、寒凝或迫退只能选其一 |
| 木修 | 荆棘护幕、噬藤回生、接枝催荣、双藤绞杀 | 即时生长有额外木气成本，寄生可换回复，双储备用于爆发 |
| 土修 | 磐甲反震、地脉养元、裂岩破阵、叠岩诀 | 地势用于反伤／回复／破阵；低伤进攻能积势，移动仍损地势 |

费用、射程、消费层数、使用次数和当前施展前提均在神通卡和配装界面公开。水、木没有增加蓄势招式。

## 有限反击

反击准备在下次自身行动开始时失效，最多回应一至两次直接攻击。基础反击不超过该次承受攻击经防御减免后的总伤害，再按反击属性、法防和护盾结算；护盾吸收的直接攻击也可触发。持续灼烧、寄生侵蚀、主动燃血和反击本身不触发反击。致命命中结束战斗，不由已倒下的一方追加反伤，避免递归与双死。

护盾与反击准备实际支付费用；消费的潮势、生长或地势不同时用于攻击或回复。反击状态展示剩余次数，伤害和等待理由进入纪要、统计及存档。

燃血聚火采用 **18 气血换 2 火＋1 通灵、1 行动、每回合一次**，不可致死，溢出的灵气不退还代价。初稿 10 血换 3 火＋1 通灵与敛焰复元组合过于划算，已在完整测量前修订。

## AI 的公开备用策略

主招清单保留，不暗改原预告；界面同时公开条件备用策略：

1. 招式仅因距离不合法时，若移动后仍付得起费用、准备和行动，先付费接近或拉开，再尝试原招。支持从远距接近两档。
2. 原招前提或费用失效，跳过该项，然后用剩余行动从已装备神通中选择合法攻击；缺气时可以调息。通用普攻作为无需灵气的安全收尾。
3. 蓄势时允许护体、调整距离和调息；资源已满且无合理操作时等待实际释放。
4. 对手有限反伤使当前进攻不划算时可存气等待。纪要记录明确理由，不用“收益低”掩盖距离或缺气处理遗漏。

固定主招阶段的确可因反应而失效；备用招仍受实际射程、行动、灵气、准备、次数和装备限制。真人结束行动保留灵气仍可用。敌方和己方自动打法共用备用规则，实战与公开阶段预测调用相同结算。

旧测试中仅用于观察成熟、过期或释放时机的片段，明确设置敌方零行动；完整战斗与预测对照则实际执行新备用行动，不能继续期待空队列自动空过。

## 当前结论

原推荐在准备预测控制器下，跨主修占比为24.2%–63.6%，壁垒最低、镇岳最高。新招样例为22.7%–86.4%，共生最高、镇岳最低；火木修订后为引燃47.0%、生息28.8%。两组各有30回合未决，详见矩阵，未把它们改判成胜负。

**神通与主动应变已经实现，平衡没有完成。** 共生在准备预测下86.4%，即时控制器下45.5%，控制器与配装偏差很大。新招不是全部更强、样例不是最优搭配，不能把每个职业的强弱归因于一个固定数字。优先复查共生的即时培植／收获与反击配合，以及壁垒、镇岳、寄生和生息的替代配装，再按对局证据逐项调整。
