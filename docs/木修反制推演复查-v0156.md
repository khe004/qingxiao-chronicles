# 木修反制推演复查 · v0.15.6

本轮继续复查共生、寄生NPC如何分配准备、进攻和恢复，采用三个问道规划修正：玩家付费破除生长、净化寄生的收益进入反制估量；候选固定队列按实战公开备用策略执行完整敌方阶段；有可选主招时保留具体预告，避免全部动作隐藏在备用策略里。

共同的职业规则、伤害、气血、灵气、六槽和实战备用策略沿用。共生可以在繁花进攻、蔓屏护体与回春恢复之间消费同一生长；寄生NPC的原六招没有回春，公共净息仅在有灼烧时合法。本轮没有为寄生额外加回复招式。

## 采用依据

四个单行动反制夹具以前漏选有效的破除／净化，现能选择并支付对应成本；它们是有限策略假设的行为检查，不是宣称旧引擎无法使用这些招式。两项退距对照仍消费唯一行动，不同时免费反制。一项预告回春失去生长的局面，原模型只跳过失败招，采用版与实战一样调息后换用青叶矢。

`test-wood-counterplay.mjs`另外比较595个完整敌方阶段：六类玩家、十一位NPC、三个距离，含空队列、已装备组合和移动组合，实际应对、准备、双方灵气、剩余队列与阶段结束字段一致，原局面不被修改。

首个“完整备用招”候选把空预告也当作完整行动，因路径成本较少被优先选中，未通过已有木土预告回归；已记录并拒绝。采用版在存在其他候选时去掉空路径，没有改变实战等候条件。
